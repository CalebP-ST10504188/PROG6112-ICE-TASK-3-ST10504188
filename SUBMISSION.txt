Features added
--------------
- Step-by-step algorithm playback: play/pause, step back/forward, scrubber, speed, clickable trace
- Plain-English explanation of every step, with the live queue/stack/priority queue
- Real-time source-to-target pathfinding (Dijkstra's with early stopping and path tracing)
- Hover a vertex after BFS/Dijkstra's to trace its path
- New algorithm: Kruskal's minimum spanning tree (union-find), including spanning forests
- Drag-and-drop vertices, drag-to-connect edges, edge-weight editing, right-click menus
- Validation with clear error messages; Dijkstra's refuses negative weights
- Save/load .graph files, bundled examples, PNG export, keyboard shortcuts, dark theme
- Bug fixes: Dijkstra's single-vertex crash, Edge equals/hashCode contract, weight-overflow crash, pom.xml Java version and main class
